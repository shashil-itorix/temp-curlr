Install curlr

A minute, tops — the extra steps are only because the beta isn't OS-signed yet.

  1. Download the .dmg using the button above.
  2. Open it and drag curlr into your Applications folder.
  3. Clear the quarantine flag macOS adds to unsigned apps — run this once in Terminal:
    xattr -dr com.apple.quarantine /Applications/curlr.app
  4. Launch curlr from Applications. Done — future updates install themselves.
