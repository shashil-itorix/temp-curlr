Step-by-step: access the beta

Takes about a minute. You'll only do step 3 for this beta.

  1. Download the .dmg file using the button above.
  2. Double-click the downloaded .dmg file and drag curlr to the Applications folder, as shown in the video.
  3. Open a new Terminal window and run the following command:
    xattr -dr com.apple.quarantine /Applications/curlr.app
    Note: this step is only required for the current beta build — it removes the quarantine flag macOS adds to unsigned apps. It will not be needed in the production release.
  4. Done! You're all set to try out the curlr beta.
